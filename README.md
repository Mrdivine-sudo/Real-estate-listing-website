# 🏠 Real Estate Listing Website

Online property listing platform for **Nkea bu nke anyi properties Ltd**, Enugu.

### Features
- Search & filter by location, type, keyword
- Property cards with price, image, description
- WhatsApp enquiry — one click, message auto-filled
- Mobile-first responsive design

### Tech
HTML, CSS, JavaScript
